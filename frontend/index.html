How PBRMS Works

Four simple steps to seamless bicycle rentals

1. Select Station

Choose any nearby docking station and browse available bicycles by type and hourly rate.

2. Rent Bicycle

Confirm rental instantly. The bicycle status changes to Rented in real time across the system.

3. Return Anywhere

Dock the bicycle at any station with available capacity. Real-time duration is captured.

4. Automatic Fare

Fare is accurately calculated: Duration (Hours) × Rate. Simulated payment ledger updates instantly.
